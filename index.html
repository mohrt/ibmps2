First, load the ROMs

These IBM machines can't switch on without their BIOS, IBM's program in their ROM chips. It is still under copyright, so it isn't included here: choose or drop your own copy. It stays in this browser and is never sent anywhere. The browser remembers it, so you only need to do this once.

Machine

  • ROMs Required

Pick the files, or a .zip containing them. A whole ROM collection works too: every machine's ROMs in it are found and kept. The 86Box emulator's collection has them in its machines folder (ibmps2_m30_286, ibmps2_m30, ibmps2_m25, ibmps1_2011, ibmat, ibmxt, ibmpc82), and the character ROM in video/mda.

Release to load the ROMs

A: No disk has saved changes
B: No disk has saved changes

Drop .img, .ima, .vfd or .zip disk images anywhere on the page to put them in A: (onto B:'s row for B:). Several at once, such as all the disks of a program, give each drive a Swap menu for changing disks.

Release to insert

Click or press a key to start sound

Keys type on the machine as labelled (Cmd stays with the browser; Option is Alt). Ctrl-Alt-Del is on the toolbar, since browsers keep it. On the PS/2s and PS/1, click the screen to use the mouse (Esc lets it go). The PC and XT keyboards have no separate arrow keys: the arrows are the number pad's, with Num Lock off.
